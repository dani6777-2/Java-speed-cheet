# Java-speed-cheet

Todo lo básico para Java

## Descripción

Este repositorio contiene ejemplos básicos y esenciales para aprender y practicar Java. Está diseñado para ayudar a los principiantes a familiarizarse con los conceptos fundamentales de Java.

## Contenido

- **Estructura de un Programa Java**: Ejemplos de la estructura básica de un programa en Java.
- **Tipos de Datos y Variables**: Explicación y ejemplos de los diferentes tipos de datos y cómo declarar variables.
- **Operadores**: Ejemplos de operadores aritméticos, lógicos, y de comparación.
- **Estructuras de Control**: Ejemplos de estructuras de control como if-else, switch-case, bucles (for, while, do-while).
- **Funciones y Métodos**: Cómo declarar y utilizar funciones y métodos en Java.
- **Clases y Objetos**: Conceptos de programación orientada a objetos en Java, incluyendo la creación de clases y objetos.
- **Herencia y Polimorfismo**: Ejemplos de herencia y polimorfismo en Java.
- **Manejo de Excepciones**: Cómo manejar excepciones en Java.

## Requisitos

- JDK (Java Development Kit) 8 o superior
- Un IDE o editor de texto (por ejemplo, IntelliJ IDEA, Eclipse, VSCode)

## Instalación

1. Clona este repositorio en tu máquina local:
    ```bash
    git clone https://github.com/dani6777-2/Java-speed-cheet.git
    ```
2. Abre el proyecto en tu IDE favorito.
3. Compila y ejecuta los ejemplos según sea necesario.

## Uso

Cada directorio dentro del repositorio contiene ejemplos específicos de diferentes conceptos de Java. Puedes navegar por los directorios y ejecutar los archivos `.java` para ver ejemplos en acción.
